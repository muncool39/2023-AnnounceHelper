# AnnounceHelper 🗣
소프트웨어공학 : ChatGPT와 함께하는 프로그래밍 챌린지 과제 - AI 기술을 활용한 음성 분석기

## Overview 🌐
**AnnounceHelper** 는 AI API를 활용하여 사용자의 발표 연습을 돕기 위한 서비스입니다.

## How it Works 🛠️
### 음성 발음 평가
사용자가 분석받고자 하는 오디오 파일과 대본 텍스트 파일을 업로드 하고 분석 시작을 요청하면 API 호출을 통해 결과를 반환받을 수 있습니다.
